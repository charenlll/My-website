02 / INDEPENDENT GAME

渡魂

独立开发中的浏览器卡牌 Roguelite Demo

把每一场战斗的出牌决定，延伸成下一场战斗的牌组与资源取舍。

项目目标

设计一个能反复尝试的短流程：玩家在连续战斗中学习规则，通过战后选牌调整策略，而不是只依靠单场输出。

我的职责

独立完成玩法规则、卡牌与敌方意图配置、界面实现、存档和测试。使用 TypeScript 开发浏览器版本。

关键设计

每轮包含三场战斗；胜利后从三张牌中选一张。灯火限制出牌，浊念牌占据手牌或消耗资源，让选择产生后续影响。

当前成果

已完成可运行的序章与普通对局 Demo。固定种子可复现牌序、敌方意图和奖励，便于定位并验证问题。

项目仍在开发；页面展示当前已完成的 Demo 内容。

03 / INTERNSHIP PROJECT

弹珠活动

Construct · 产品与运营实习

把活动目标拆成玩家可理解的参与流程、奖励规则和可执行的配置方案。

项目目标

为海外社交产品设计游戏化活动，吸引用户参与，并结合奖励、兑换等节点推动充值与金币消耗。

我的职责

负责 PRD、玩法原型、数值设计、开发对接、验收和资源配置，跟进活动从方案到上线。

关键设计

梳理弹珠参与、奖励与规则说明；将视觉稿和交互原型对应，统一开发、设计和运营对玩法的理解。

实际结果

活动覆盖菲律宾、缅甸、印尼和华语市场，约一万人参与，带动充值与金币消耗增长。无可靠增长比例，不作百分比表述。
