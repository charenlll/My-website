02 / INDEPENDENT GAME

渡魂

独立开发 · 剧情驱动的卡牌冒险 Demo

与摆渡人进入亡魂的记忆，通过对话和卡牌对局理解执念，完成告别，并把信物带回驿站。

设计目标

让剧情、战斗和收藏形成同一段经历：认识人物，理解其执念，在战斗中处理干扰，最后通过信物记住这次告别。

个人职责

独立完成规则与章节设计、卡牌及敌方意图配置、界面开发、存档和测试；使用 TypeScript 开发浏览器 Demo。

当前内容

已接入序章、驿站和第一章《满溢》的剧情与遭遇流程；《满溢》包含六场固定战斗、三场可选战斗。普通对局另有随机抽牌与战后选牌。

仍需验证

多场战斗的差异是否足够明显、资源与减费组合反馈是否清楚，以及可选战斗能否形成真正的取舍。

进入记忆→理解执念→卡牌对局→获得信物→返回驿站
01 / STORY & HUB

故事从驿站出发，也回到驿站

序章用对话和三场逐步变化的战斗介绍灯火、手牌与执念。章节结束后，信物留在驿站，成为可再次查看的故事记录。

02 / BATTLE SYSTEM

用资源和出牌顺序化解执念

战斗在限定回合内降低目标执念。灯火用于出牌，敌方意图会干扰资源或牌组。绯川每回合首次获得灯火后，可让下一张普通牌费用降低一点；玩家需要判断何时补充资源、如何安排出牌顺序。

03 / DESIGN EXAMPLE · 满溢

把“虚假的账目”写进战斗规则

《满溢》围绕交易、责任与无法停止的补救展开。敌方意图“账目膨胀”会向弃牌堆加入“虚账”，并恢复执念；虚账留在手中还会继续复制。牌组越来越难运转，玩家需要用“清账”移出浊念。这个机制让剧情里的失控账目成为实际的战斗压力。

本段仅说明公开作品集所需的规则与主题，不涉及章节结局。

04 / COLLECTION & DECK

战斗结束后，选择仍会留下影响

战后奖励改变本次牌组；永久解锁的卡牌可用于局外初始牌组编辑。人物页面呈现绯川的特性与专属牌，信物录保存章节留下的纪念。信物目前承担叙事收藏功能，不提供战斗数值增益。

当前定位为具有局内构筑要素的叙事卡牌冒险。完整随机地图、系统化人物成长等内容仍属于后续规划。

03 / INTERNSHIP PROJECT

弹珠活动

Construct · 产品与运营实习

把活动目标拆成玩家可理解的参与流程、奖励规则和可执行的配置方案。

项目目标

为海外社交产品设计游戏化活动，吸引用户参与，并结合奖励、兑换等节点推动充值与金币消耗。

我的职责

负责 PRD、玩法原型、数值设计、开发对接、验收和资源配置，跟进活动从方案到上线。

关键设计

梳理弹珠参与、奖励与规则说明；将视觉稿和交互原型对应，统一开发、设计和运营对玩法的理解。

实际结果

活动覆盖菲律宾、缅甸、印尼和华语市场，约一万人参与，带动充值与金币消耗增长。无可靠增长比例，不作百分比表述。
